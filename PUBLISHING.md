1. Create a public GitHub repository named exactly `agungzippo`.
2. Upload `README.md` and the complete `assets` folder.
3. Replace the LinkedIn and portfolio placeholders in the Connect section.
4. Add repository links to each selected project when those repositories are public.
5. Commit to the default branch. GitHub will display the README on your profile.
